## Mode 3 Record — Rules Applied

The following rules were followed when filling in the above columns:

1. **Actual Result is written as observed fact** — not "same as expected" or "works correctly". Each entry describes exactly what appeared on screen or in the network response.
2. **Status is binary** — `Pass` if the Actual Result matches the Expected Result exactly; `Fail` if there is any discrepancy, even a minor wording difference in the error message.
3. **Only Actual Result and Status were modified** — all other columns are unchanged from the original TC document.
4. **Fail entries include diagnostic notes** — the Notes column records observable evidence (HTTP status code, console errors, missing UI element) to support root-cause analysis.
