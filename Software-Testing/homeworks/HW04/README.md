## 3. Project Structure

This repository is organized to facilitate quick navigation and review of all automation artifacts, scripts, and execution reports:

### AI Agent Configuration

- `.agents/` — Custom AI agent configuration, containing the definitions of custom skills (e.g. `wat-spec`, `wat-design`, `wat-build`, `wat-report`), subagents (`ui-explorer`), and MCP integrations used to automate this testing workflow.
- **Demo Video Link:** [YouTube URL](https://youtu.be/Q5tpUDpfqME).

### Documentation & Artifacts

- `docs/fr-01/` — Specification, Test Cases, and Bug Report for **FR-01 (Account Registration)**.
- `docs/fr-03/` — Specification, Test Cases, and Bug Report for **FR-03 (Forgot Password & Password Reset)**.
- `docs/fr-17/` — Specification, Test Cases, and Bug Report for **FR-17 (Coupon Management)**.
- `docs/audit/ai/` — Monthly AI audit logs detailing interactions and manual revisions for each feature.
- `screenshots/` — Bug screenshots and evidence supporting the bug reports.

### Consolidated Reports (`reports/`)

- `reports/main-report.md` — The main assignment report including the automation summary and AI gap analysis.
- `reports/bug-report.md` — The consolidated bug report aggregating defects across all automated features.
- `reports/ai-audit-report.md` — The compiled and formatted AI Audit Report for the entire assignment.
- `reports/ai-critique.md` — The mandatory AI critique evaluating the AI's performance and lessons learned.

### Automation Code (`e2e/`)

- `e2e/data/` — JSON files containing all test data used for data-driven testing.
- `e2e/pages/` — Page Object Model (POM) classes grouping locators and actions (divided into `web/` and `admin/`).
- `e2e/tests/` — Playwright test scripts (`.spec.ts` files) executing the steps defined in the Test Case documents.
- `e2e/fixtures/` — Custom Playwright fixtures handling preconditions, authentication, and data injection.

### Execution Reports

- `playwright-report/` — Contains the HTML execution reports generated by Playwright.  
  _(Note: Reports are organized into subfolders `fr-01/`, `fr-03/`, and `fr-17/` for easier reviewing)._
