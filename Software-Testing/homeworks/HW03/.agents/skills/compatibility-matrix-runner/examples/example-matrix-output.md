# Screenshot Naming Convention — Generic Web Admin Panel

> **Student ID:** 23127449@student.hcmus.edu.vn  
> **Generated by:** `compatibility-matrix-runner` skill (v1.0.0)

## Naming Convention

`{os-slug}_{browser-slug}_{device-slug}_{screen-id}_{status}.png`

| Segment      | Format                        | Examples                                                  |
| ------------ | ----------------------------- | --------------------------------------------------------- |
| os-slug      | lowercase, hyphens, no spaces | `windows-11`, `macos-ventura`, `android-14`, `ios-17`     |
| browser-slug | lowercase, hyphens            | `chrome`, `firefox`, `safari`, `edge`, `samsung-internet` |
| device-slug  | lowercase                     | `desktop`, `tablet`, `phone`                              |
| screen-id    | lowercase screen identifier   | `a2`, `a4`, `a5`                                          |
| status       | outcome                       | `pass`, `fail`                                            |

**Examples:**

- `ios-17_safari_phone_a2_fail.png` — iOS 17 / Safari / Phone / Screen A2 / Failed
- `windows-11_chrome_desktop_a4_pass.png` — Windows 11 / Chrome / Desktop / Screen A4 / Passed
- `macos-ventura_safari_desktop_a5_pass.png` — macOS Ventura / Safari / Desktop / Screen A5 / Passed
