# Example: Session Templates

> SUT: Generic Web Admin Panel | Task T1 | 1 participant shown

This file contains two examples:

1. `observation-template.md` — the master reference with full instructions
2. `session-notes/P1-session.md` — a per-participant copy ready to fill in

## File 1: `observation-template.md`

_Master reference — do not fill in this file directly. Use `P{n}-session.md` files instead._

```markdown
# Observation Template (Master Reference)

> **SUT:** {sut_name}  
> **Generated by:** `usability-test-designer` skill (v1.0.0)  
> **Date:** {YYYY-MM-DD}
>
> **PURPOSE:** This file is the blueprint for all `P{n}-session.md` files. Do NOT fill in this file. Each participant has their own `P{n}-session.md` copy.
>
> **FIELD GUIDE:**
>
> - Fields marked `[FACILITATOR]` are filled by the session facilitator (the researcher) during or immediately after the session.
> - Fields marked `[PARTICIPANT]` are filled by the participant themselves (used in `unmoderated-remote` format; facilitator may also fill these in `moderated` sessions by transcribing what the participant says).
> - Fields marked `[AI-GENERATED]` are pre-filled by the skill and should not be changed unless the task scenario was revised after approval.

## Pre-Task Briefing Checklist

_`[FACILITATOR]` Check each item before handing the task to the participant._

- [ ] Participant briefed: "We are testing the system, not you. There are no wrong answers."
- [ ] Think-aloud explained: "Please say out loud everything you are thinking as you work."
- [ ] Think-aloud practised with warm-up task (e.g. "Find today's weather in your city online") — approximately 60 seconds; do not count this in time-on-task
- [ ] Recording consent obtained and confirmed
- [ ] Task scenario printed / displayed on separate screen — not yet visible to participant
- [ ] Test account verified: logged in, clean state (no pre-existing data from prior sessions)
- [ ] Stopwatch ready
```
