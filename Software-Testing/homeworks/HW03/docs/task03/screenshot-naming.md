Use this method if BrowserStack's annotation tool is unavailable or does not embed text correctly.

1. Take the screenshot from BrowserStack (save as PNG).
2. Open the PNG in **Microsoft Paint**.
3. Click the **Text tool** (`A`) in the toolbar.
4. Click near the **top-left** of the image content area.
5. Set font size to **16** or larger, colour to **white** (`#FFFFFF`).
6. If the page background is white, first draw a filled dark rectangle (`#000000`) where the text will go, then switch to the Text tool and type the overlay.
7. Type: `23127449@student.hcmus.edu.vn`
8. Choose **File → Save As → PNG**. Use the naming convention filename. Do **not** save as JPEG (lossy compression degrades screenshots).

**macOS (Preview):**

1. Open the PNG in **Preview**.

3. Click the top-left of the image.
4. Type: `23127449@student.hcmus.edu.vn`
5. Set font size ≥ 16, colour white. Use the **Rectangle** shape tool with a dark fill behind the text if the page background is white.

## Overlay Placement Rules

| Rule                  | Requirement                                                                          |
| --------------------- | ------------------------------------------------------------------------------------ |
| **Position**          | Top-left corner of the screenshot, within the page content area                      |
| **Minimum font size** | 14pt / 14px                                                                          |
| **Contrast**          | White text on a dark background (or dark text on a light background if unavoidable)  |
| **Legibility**        | Must be readable at 100% zoom without zooming in                                     |
| **Coverage**          | Must not cover primary content entirely — place in a padding/margin area if possible |
| **Do not crop**       | Overlay must be fully visible, not clipped at the edge of the image                  |
