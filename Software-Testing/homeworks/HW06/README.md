### Key Folders Explained

- `docs/apis/`: The core documentation folder for each API. Contains the formalized `CONTRACT.md`, the multidimensional `test-cases.md`, the structured `bug-report.md`, and the formatted `test-cases.xlsx` Excel exports.
- `docs/openapi/`: Contains the OpenAPI 3.0 specification (`openapi.yaml` and path references) generated by the AI based on the formal contracts. Used by the backend's Swagger UI (`http://localhost:3000/api-docs`).
- `postman/`: Contains the raw execution artifacts. The `collections/` folder holds the JSON configurations and data-driven CSVs. The `reports/` folder stores the beautiful Newman HTML reports generated after execution.

## 4. How to Run Tests Locally

Follow these steps to manually run the test suite and generate both HTML and JSON reports.

### 4.1. Install Newman Dependencies

```bash
# Install Newman at root
npm install
```

### 4.2. Start the SUT (Backend)

The backend must be running before tests can execute.

```bash
cd backend
npm install
node server.js
```

_The server will start on `http://localhost:3000`. Leave this terminal open._

### 4.3. Run Newman Tests

In a new terminal window at the root of the project, execute the tests. You can run all tests or target a specific API.

**Run All Collections:**

```bash
npm run test:all
```

**Run a Specific Collection:**

```bash
npm run test:fr01  # Runs POST /api/register
npm run test:fr07  # Runs POST /api/cart
npm run test:fr17  # Runs POST /api/admin/coupons
```

### 4.4. View Reports

After execution, the following reports are generated automatically:

1. **HTML Report:** Open the corresponding file in `postman/reports/` (e.g., `fr01-report.html`) in any web browser for a detailed, interactive summary.
2. **JSON Summary:** Raw JSON outputs are saved to the `docs/apis/{slug}/newman-summary.json` folders, which are used by the AI to parse actual results.
